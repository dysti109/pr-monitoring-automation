# PR 수집·분석 기준

이 문서는 특정 회사명이나 경쟁사 명단과 분리해 공개할 수 있는 공통 운영 기준이다. 실제 대상 기업, 브랜드·서비스명, 검색어, RSS 주소는 로컬 설정 파일에서 관리한다.

## 1. 수집 대상 그룹

- **A. 주 대상과 브랜드:** 주 대상이 직접 발행한 보도자료·공식 콘텐츠와 주 대상을 다룬 제3자 보도를 수집한다. 브랜드명만 언급된 경우에는 동명이인·동명 서비스가 아닌지, 실제 사업과 관련 있는지 원문에서 확인한다. 비공식 게시물은 설정에서 허용된 경우에만 포함한다.
- **B. 지정 대상:** 사용자가 로컬 설정에 등록한 기업의 사업·제품·서비스·고객·계약·실적·제휴를 직접 다룬 제3자 언론 보도를 수집한다. 기업 자체 홍보 게시물과 단순 나열은 제외한다.
- **C. 유사 사업자:** 고정 명단에 한정하지 않고, 주 대상과 산업·서비스·고객군이 실질적으로 겹치는 기업을 찾는다. 기사에 포함할 때는 사업 중첩 근거를 기록한다.

한 콘텐츠가 여러 그룹에 해당하면 A > B > C 순으로 하나만 지정한다. 비공식 게시물은 A 그룹에서만 설정에 따라 수집하며, B/C 그룹은 언론 보도 중심으로 본다.

## 2. 검색과 후보 확인

검색은 모든 웹페이지를 자동으로 열거하는 방식이 아니라, 설정된 기업명·브랜드·제품·서비스·고객·계약 키워드로 후보를 찾고 원문을 확인하는 방식이다.

- Google News RSS와 접근 가능한 일반 웹 검색을 후보 발견에 이용한다.
- 네이버 뉴스도 교차 검색 대상으로 삼는다. 접근 제한이나 검색 오류가 발생하면 검색 완료로 간주하지 않고 한계로 기록한다.
- 사전 수집은 세 회차로 나눈다. 09:05에는 회사·브랜드명, 09:25에는 제품·서비스·고객·계약 관련어, 09:50에는 표기 변형과 구체 검색어를 중심으로 후보를 추가한다. 10:01 최종 단계에서 마감 시각까지의 원문과 발행 시각을 확인하고 중복 정리·이슈 구성을 마친다.
- 최종 단계에서는 후보 URL을 합치고 원문에서 매체, 제목, 발행 시각, 대상과의 실제 관련성을 확인한다. RSS의 발행 시각만으로 기간 적격성을 확정하지 않는다.
- 원문을 열지 못한 경우 확인한 정보의 범위를 표시하고, 확인하지 않은 내용을 사실처럼 단정하지 않는다.

## 3. 포함·제외와 중복 처리

포함 여부는 기사 제목의 키워드 일치만으로 결정하지 않는다. 원문에서 대상이 실제 주체로 다뤄지는지, 사업·제품·서비스와 직접 연결되는지 확인한다.

광고성 콘텐츠, 단순 인사·부고, 무관한 동명이인·동명 제품, 기간 밖 게시물, 기업명이 한 번 나열된 정도의 콘텐츠는 제외한다. 지정 대상의 자체 뉴스룸·블로그·행사·모집 게시물도 제3자 언론 보도가 아니면 제외한다.

같은 URL은 한 번만 남긴다. 서로 다른 매체의 기사는 각각 보존하되 같은 사건을 다루면 하나의 이슈로 묶고 대표 기사와 추가 보도를 연결한다. 기사·게시물 수와 이슈 수는 따로 집계한다.

## 4. 기간과 평가

수집 기간은 요청이 별도로 없으면 전날 오전 10시부터 당일 오전 10시까지 한국시간 기준으로 설정한다. 월요일에는 기본적으로 직전 금요일 오전 10시부터 시작하며, 사용자가 지정한 기간이 있으면 그 기간을 우선한다.

- **중요도:** 주 대상의 사업·시장 판단에 주목할 가치가 있는 정도를 본다. 사업 연관성, 고객·계약 접점, 실행 사실과 파급 근거를 기준으로 평가한다.
- **위협도:** 해당 소식이 주 대상의 고객·매출 기회·제품 경쟁력에 실제 불리한 영향을 줄 가능성을 별도로 평가한다.
- **평판 신호:** 주 대상 관련 콘텐츠의 톤과 평판 위험을 원문 근거로 판단한다. 개인 의견과 확인된 사실을 구분한다.

높은 중요도가 곧 높은 위협을 뜻하지 않는다. 구체적인 근거가 부족하면 판단을 보류하고 이유를 남긴다.

## 5. 카드 구성과 출처 표시

- 동일 사건을 여러 매체가 보도하면 기사 원문 확인 수준, 출처의 신뢰도, 독립 취재 여부와 최초 보도 여부를 살펴 대표 기사를 정한다. 다른 매체의 보도도 추가 노출로 연결해 보존한다.
- 이슈 수와 개별 기사·게시물 노출 수를 구분한다. 검색 결과만 확인한 후보는 원문 검증을 마친 기사와 구분한다.
- 메일은 주 대상 관련 내용을 언론 보도와 온라인 게시글로 나눠 보여준다. 공시·정부·공공기관 등 공식 출처는 별도 공식기관 라벨로 식별한다.
- 출처 신뢰도는 원문 접근·작성 주체·정보의 구체성·독립 확인 가능성을 기준으로 표시한다. 원문을 확인하지 못한 경우 확인 범위를 함께 적고 사실로 단정하지 않는다.

## 6. 로컬 설정과 공개 범위

공개 예시 설정에는 자리표시자만 둔다. 실제 이메일 주소는 config/email-settings.local.json에, 검색 대상·검색어·브랜드·피드 주소는 config/pr-monitoring.local.json에 둔다. 두 파일은 Git 추적에서 제외한다. 공개 저장소에는 이 문서와 예시 설정만 포함한다.
